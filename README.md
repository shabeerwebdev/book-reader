# Mobile Book Reader (PWA & Web Reader)

A clutter-free, vertical-scrolling, mobile-first book reader designed for travel and focused reading.

## Features
- **Offline-First PWA:** Zero dependencies, zero build steps, runs anywhere offline.
- **Editorial Typography:** Calibrated Warm Paper (`#FAF6EE`), high-contrast charcoal text, left-aligned, glare-free.
- **Multi-Book Library:** Switch seamlessly between titles with independent reading progress and saved positions.
- **Table of Contents:** Grouped by Parts with chapter reading times and in-chapter section jump anchors.
- **Docked Selection Bar:** Bottom-anchored `[ 📖 Explain ] [ 🟡 Highlight ] [ ✕ ]` avoiding native mobile copy menu collisions.
- **Contextual AI & Dictionary:** Instant contextual explanation via Pollinations AI and English Dictionary API with offline concept glossary fallback.

## Live GitHub Pages
Deploy to GitHub Pages:
1. Go to repository **Settings** -> **Pages**.
2. Under **Build and deployment**, select **Source: Deploy from a branch**.
3. Choose **Branch: main**, folder: `/ (root)`.
4. Click **Save**. Your site will be live at `https://<username>.github.io/<repo-name>/`.
